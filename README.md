# Rock Paper Scissors

A simple interactive Rock Paper Scissors game built with React. This project is an opportunity to practice React class components, Styled Components, component structure, and event handling.

## About the Project

Rock Paper Scissors is a classic game where a player chooses Rock, Paper, or Scissors and competes against the computer. The winner is decided according to the game's rules.

## Features

- Choose between Rock, Paper, and Scissors.
- Play against the computer.
- Display the player's choice and the computer's choice.
- Calculate and display the game result.
- Keep track of the score.
- Provide a clean and responsive user interface.

*Note: These features describe the intended project. Keep only the features that are implemented in your current version.*

## Getting Started

### Prerequisites

Make sure Node.js and npm are installed on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <your-project-folder>
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open the local URL shown in your terminal to view the application.

## How to Play

1. Select one of the three choices: Rock, Paper, or Scissors.
2. The computer selects its choice.
3. The game compares both choices and displays the result.
4. The score updates according to the implemented game rules.
